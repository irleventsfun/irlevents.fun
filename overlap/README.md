# The Overlap

A browser-based test version of The Overlap relationship-fit app.

## Live path

GitHub Pages project path: `/overlap/`

## What works in this version

- Couple and single-person modes
- 12 values/threshold assessments
- Local autosave using browser storage
- Reusable partner comparison links
- Same-device partner testing
- Return-code flow for cross-device prototype testing
- Comparison results and overlap bands
- 14-day plan builder
- DEAR MAN preparation
- Conversation chess timer
- Creator-method notes
- Book and relationship-tool library
- Demo data

## Prototype limits

This is a static GitHub Pages app. Answers are stored only in the current browser. It does not yet provide cloud accounts, real email delivery, secure server-side invitations, automatic cross-device syncing, or a shared database.

The production build needs Supabase Auth/PostgreSQL, Row Level Security, transactional email, scheduled reminders, analytics, and a privacy/deletion workflow.
